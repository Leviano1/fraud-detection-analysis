# fraud-detection-analysis

Download the dataset from Kaggle and put it in data/.

Business question: Can we detect fraudulent transactions, and what would it save?
Data: source, size, the imbalance, and why the features are anonymised (privacy).
Approach: SQL exploration → models → threshold choice.
Results: a small table of metrics, plus one or two charts from images/.
Business recommendation: savings estimate and the trade-offs.
Limitations and next steps: what you’d do with more time.
How to run it: install requirements, download the data, open the notebooks.
